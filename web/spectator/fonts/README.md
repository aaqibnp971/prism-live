# Local display fonts

Unmodified Latin WOFF2 resources extracted from the supplied `docs/design/spectator-v3.html`
bundle. IBM Plex Mono 400, 500 and 600 cover numerical and small labels; IBM Plex Sans is the
bundle's variable font for headings and prose. No font or CSS request leaves the laptop.
